The Problem

Setting up local dev environments shouldn't take hours. Yet developers face a painful choice.

🐋

Docker Compose

Simple but limited. No orchestration, no service mesh, no pipelines, no dashboards.

☸️

KinD + kubectl + Helm

Powerful but complex. 5+ tools, steep learning curve, endless YAML configuration.

Torresmo

Best of both worlds. The simplicity of Compose with the power of Kubernetes.

Features

Everything you need for local development, nothing you don't.

🚀

One-Command Setup

From zero to full stack in 30 seconds. Templates, addons, and clusters — one command.

🤖

AI-Powered CLI

Talk to your cluster in plain English. Powered by Ollama running locally.

📦

10 Built-in Addons

Redis, Postgres, Kafka, MongoDB, Prometheus, Grafana, and more — pre-configured.

🔧

Local Pipelines & Workflows

Native HCL pipelines + run GitHub Actions workflows locally via act. Dependency graphs and parallel execution.

🔄

Brownfield K8s Support

Existing Kubernetes YAML manifests work without modification. Supports apps/v1, v1, and batch/v1 apiVersions.

📸

Snapshots

Save and restore your entire cluster state. Perfect for risky migrations.

📊

Dashboard with Live Logs

TUI and web dashboard. Click any pod for live log streaming and an interactive terminal.

How It Works

Three steps. That's it.

Install

brew tap franchialan/torresmo
&& brew install torresmo
2

Create

torresmo create cluster
-t go-api --name dev

Ship

torresmo dashboard --web

Installation

Get up and running in under a minute.

Homebrew (macOS / Linux)
$ brew tap franchialan/torresmo
$ brew install torresmo
Shell script
$ curl -fsSL https://raw.githubusercontent.com/franchialan/torresmo/main/scripts/install.sh | bash
From source
$ go install github.com/torresmo-dev/torresmo/cmd/torresmo@latest
